# Referencias históricas incluidas

`Evaluacion_3.pdf` es la consigna académica proporcionada; `Project_5_RFP.pdf` es la fuente de requisitos del producto. Se incluyen como referencias distintas. `evaluation-2/` contiene decisiones, ADR, reglas y trazabilidad del corte anterior. Son documentos históricos: algunos resultados y diagramas reflejan fechas y código anteriores. Los links a matrices/resultados o runbooks excluidos apuntan a notas de sustitución que evitan rutas locales y comandos de despliegue obsoletos. Para ejecutar y validar esta entrega, seguir exclusivamente `../../README.md` y no reutilizar los runbooks E2 como instrucciones del entorno actual.

Se omite el runbook de demo Docker anterior. El entorno E3 está aislado y temporal; no requiere Docker, Neon ni datos locales.
